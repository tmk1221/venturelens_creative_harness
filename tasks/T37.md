# T37 shorts that are really vertical: B-roll at the cut's aspect, export that says its format, render checks
Why: the Sample sample is a 60 s short in 4:5 (LinkedIn) and 9:16, derived from a 16:9 remote recording. Today
generation defaults to `aspect: "16:9"` (`recipes/node_types.py:51,70,76`) whatever the cut is; the OTIO export never
mentions the cut's aspect (`export/`); and `recipes/workers/asset_verify.py` checks only resolution, fps and duration.
Read first: `edit/ops.py` (`derive_cut`, `Cut.aspect`), `recipes/instantiate.py`, `recipes/node_types.py`,
`export/{otio_export,_clips,_tracks}.py`, `recipes/workers/asset_verify.py`, T09 spec,
`~/cc/vl/brain/projects/post-animation-recovery-2026-09-16.md` (render-contract lessons), and the `animate` skill
§3–4 (hold the last frame), read only.
Build:
1. Instantiating a recipe on a span takes the aspect from the span's cut; if the chosen model doesn't offer it
   (T18 item 1 data; fixture until then), pick the nearest offered aspect that covers the frame and record
   `crop_to` on the node so the card shows "generated 9:16, cropped to 4:5".
2. Export: timeline name and metadata carry the cut's aspect and intended resolution (4:5 → 1080x1350, 9:16 →
   1080x1920, 16:9 → 1920x1080), e.g. `<cut>_4x5_v003.otio`; a README line next to the export says the A-roll is
   16:9 and is reframed in Resolve. Whether Resolve honours the metadata is H1's question; do not script Resolve.
3. `asset.verify` render contract for generated video: has a video stream; fps equals the project's; duration ≥ the
   span's length (live action is ceil(beat)+1 s, already in `video_generate.py`); the last 0.5 s is not a frozen
   duplicate of an earlier frame unless the brief asks for a hold; aspect matches `crop_to` or the cut's. Each
   failure is a one-sentence cause on the card.
Acceptance: pytest: a 4:5 cut instantiates 4:5 (or nearest + `crop_to`); export names/metadata for each aspect; verify
fails a too-short clip, wrong fps, frozen tail (ffmpeg-generated fixtures). All suites green.
Out of scope: automatic reframing of the 16:9 A-roll (done in Resolve), captions, alpha/overlay checks.
