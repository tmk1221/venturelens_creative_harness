# T28 graph view: fluid and readable (2026-09-22)
Travis: dragging is laggy; node text unreadable; wants a more aesthetic, fluid canvas ("I thought React Flow would be a lot more fluid").
Root causes to fix (verified by reading `web/src/enrich/GraphPanel.tsx`):
1. LAG: `<ReactFlow nodes={rf.nodes}>` is fed straight from a `useMemo` with no `useNodesState`/`onNodesChange`; positions are re-derived from props (and dagre re-run) on every parent render (SSE/poll refresh), so every drag fights a re-layout. Use `useNodesState`/`useEdgesState`, run dagre ONCE per workflow structure (node/edge ids), apply status changes by updating `node.data` in place, never rebuild the node array on a status poll. Memoize the custom node component. Persist positions on drag stop as now.
2. UNREADABLE: the legacy dark theme sets light body text while nodes use pale pastel backgrounds with inline styles; labels include full 32-hex ids. Design nodes for the dark canvas.
Aesthetic — borrow from node-banana / tersa (MIT; the React Flow research doc in the brain lists them: `~/cc/vl/brain/projects/post-v3-research-react-flow.md` §3) and React Flow's own UI components (Base Node, Labeled Handle, Node Status Indicator — MIT via shadcn registry; port what you need, no Tailwind v4 dependency required):
- Node = dark card (matches `.visual-rail-card` palette from legacy-look.css), header with a HUMAN name ("Start frames", "Pick a frame", "Motion prompt", "Video", "Verify", "Approve", "Reference image", "Brief") + small type icon; body shows the thing: output thumbnail(s) for image/video nodes (from the artifact endpoint; a picked variant highlighted), the first line of a prompt for text nodes, a state pill (plain words: Waiting for a pick / Generating… / Ready to approve / Approved / Out of date / Failed: <cause>); cost badge when known. No raw ids anywhere (tooltip only).
- Handles: coloured by handle type (image/video/prompt/audio/character/brand), labelled on hover; edges use the source handle colour; animated only while running.
- Canvas: dark background with subtle dots, smooth pan/zoom, fitView with padding on open, MiniMap off, Controls restyled to the theme. Keep the full-screen overlay, top-bar palette (rename to plain words), inspector on the right with the same dark styling and editable params (not raw JSON first).
- Interactions must feel instant: dragging, connecting, selecting; no network call in the drag path.
Acceptance: Playwright measures a 40-step node drag with no long task > 50 ms (PerformanceObserver) and asserts the node ends where dropped; existing enrich e2e still passes; screenshot `docs/screens/t28-graph.png` of the demo beat's graph after Generate + Pick (thumbnails visible); build/tests green. Only touch `web/src/enrich/` (+ its e2e) and add CSS in a new `web/src/enrich/graph.css`.
