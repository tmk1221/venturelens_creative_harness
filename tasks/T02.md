# T02 post_core model + store
Goal: the v3 data model and the only persistence layer.
Read first: `docs/ARCHITECTURE.md`; for the proven pattern, `~/cc/post-transcript-first/backend/app/transcript.py` (word anchors, optimistic revision, lock, atomic write, undo) — read-only.
Build `packages/post_core/` (pyproject: pydantic v2, pytest; package `post_core`):
- `model/`: pydantic models, all with `id` + `schema_version`: Project, Shoot, Source (abs path, fps as rational, start timecode, role, proxy, peaks, content fingerprint),
  SyncGroup (source ids + offsets in seconds), Word (id,text,start,end,speaker,confidence), Transcript (sync_group_id, provider, words, fingerprint),
  Cut (aspect, parent_cut_id, sections, passages, spans, variant label), Passage (sync_group_id, start_word_id, end_word_id, trims, angle source_id, framing),
  Span (layer: picture|overlay|audio, start/end word anchor = (transcript_id, word_id), kind, workflow_id, provenance human|agent),
  Asset (role, node_id, content_hash, brand_kit_hash, path), Approval (content_hash, by, at), Deliverable (cut_id, width, height, captioned).
- `store/`: project dir layout `<root>/.post3/{project.json,shoots/,transcripts/,cuts/,workflows/,assets/,approvals.json}`; `read(kind,id)`, `write(kind,obj,expected_rev)`
  with per-file revision, cross-process flock, temp+fsync+rename, RevisionConflict error, refuse malformed files; snapshot undo stack per cut (cap 100) stored on disk.
- Invariants validated on write: passages reference existing words in order; spans on the same layer do not overlap; anchors resolve.
Acceptance: pytest with temp dirs: round-trip, revision conflict, concurrent writers (multiprocessing), corrupt file refusal, invariants, undo/redo.
Out of scope: graph, queue, API.
Do NOT create files under `post_core/workers/` (another task owns it).
