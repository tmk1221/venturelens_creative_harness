# T06 CLI + executor hardening
Goal: the headless front door. Everything the UI will do is a `post` command with JSON output.
Read first: ARCHITECTURE §2, `post_core/{store,graph,queue,edit,ingest}` public functions.
Carry-over from T05 (do first, in `post_core/queue/`, with tests):
1. Real concurrency: a persistent worker loop (`Executor.serve()`) using a thread pool per lane so lane limits are used, not just respected; clean shutdown marks running jobs interrupted.
2. Authorisations are data, not process state: table `authorisation(id, budget_id, scope: node ids or workflow id, covers_downstream: bool, by, at)`; each job row names the authorisation that allowed it; survives restart.
3. Replace the magic lane name with an explicit `resources: ["resolve"]` list on NodeType (additive); the executor takes the flock for declared resources.
Build `packages/post_core/post_core/cli/` (argparse, stdlib) + console script `post` in pyproject:
- `config.py`: load `<repo>/.env` and `<project>/.post3/config.json` without overriding real env vars; never print values; `post doctor` reports which keys/tools (ffmpeg, ffprobe) are present as booleans only.
- Commands (all print one JSON object; `--pretty` optional; non-zero exit + `{"error":…}` on failure): `init <root>`, `project show`, `source add/probe`, `ingest proxy|peaks|transcribe|import-transcript`, `cut new|show|op <name> --args json|undo|redo|derive`, `workflow new --recipe|show|plan|states`, `run --workflow … --authorise budget=… [--from node]`, `queue list|show <job>|cancel|serve`, `approve|revoke <content_hash>`, `budget set|show`, `export otio <cut>` (if `post_core.export` is importable, else a clear error).
- Each command is a thin call into a core function; if a core function is missing, add it to the owning package, not the CLI.
Acceptance: pytest drives the CLI via subprocess on a temp project end to end with fake node types/workers: init → add source (lavfi media) → import transcript → new cut → two ops → undo → workflow plan shows cost → run refused without authorisation → run with budget → states done → approve → queue survives a killed `serve` and resumes. `post doctor` never leaks a secret (test with a fake key in a temp .env).
Only touch `post_core/cli/`, `post_core/queue/`, `graph/types.py` (the additive field), tests, and pyproject (console script). Another agent may be editing pyproject for the `opentimelineio` extra — re-read it before editing and keep both changes.
