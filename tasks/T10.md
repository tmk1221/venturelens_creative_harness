# T10 post_api: HTTP over the core
Goal: the UI's backend — a thin FastAPI layer; no business logic here.
Read first: ARCHITECTURE §2, `post_core/cli/` (the API exposes the same operations; share the same core functions — if logic lives only in the CLI, move it into the owning core package first).
Build `packages/post_api/` (own pyproject: fastapi, uvicorn, post_core as path dep; venv at packages/post_api/.venv):
- App factory `create_app(registry_path)`; project registry (list/add/open by id; many projects addressable at once — NO module-level "open project" global; every route is `/api/projects/{pid}/…`).
- Routes mirroring the CLI: project, sources, ingest jobs, transcripts (words paged by range for long transcripts), cuts (get, `POST …/ops` with `expected_rev` → 409 on conflict with the current rev in the body, undo/redo, derive), workflows (get/plan/states), run (authorisation body; 402-style refusal JSON when spend is not authorised), queue (list/show/cancel), approvals, budgets, export otio, doctor.
- Media: `GET …/media/{source_id}/proxy` with HTTP Range support, `…/peaks`, `…/assets/{content_hash}`; path always resolved from ids server-side, never from a client-supplied path; URLs carry the content fingerprint so browsers never replay a stale file.
- Events: one SSE stream per project (`…/events`) fed from the queue's event table by polling `seq` (works across processes), with `Last-Event-ID` resume.
- Executor lifecycle: app lifespan starts `Executor.serve()` in a background thread per opened project and stops it cleanly.
- Typed contract: pydantic response models everywhere; `python -m post_api.openapi > web/src/api/openapi.json` and an npm script (`openapi-typescript`) documented for generating TS types. Unknown routes under `/api` return JSON 404, never index.html.
Acceptance: pytest with FastAPI TestClient on temp projects + fake node types: two projects open at once; op conflict → 409; Range requests return 206 with correct bytes; SSE resumes from Last-Event-ID; spend refused without authorisation; path traversal attempts rejected; OpenAPI generation runs.
Only touch `packages/post_api/` (and core packages only to move logic out of the CLI, minimal).
