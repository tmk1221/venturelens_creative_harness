# T07 ingest: transcripts, proxies, peaks
Goal: turn source files into what the editor needs, with pluggable transcription.
Read first: T02 model (Source, SyncGroup, Transcript, Word), T03 contract. Reference (read-only): `~/.claude/skills/footage-ingest/scripts/transcribe.py` for Deepgram request/response shape.
Build `packages/post_core/post_core/ingest/` (stdlib only; ffmpeg/ffprobe via subprocess):
- `probe.py`: ffprobe → Source fields (fps as rational, duration, start timecode, width/height, audio streams, fingerprint = size+mtime+first/last 1MB sha).
- `transcribe/base.py`: `TranscriptProvider` protocol `transcribe(audio_path, opts) -> Transcript`; registry by name. `deepgram.py` (nova-3, urllib, key from env `DEEPGRAM_API_KEY`, maps words/speakers/confidence; NEVER called in tests — test the response mapper with a fixture JSON). `importer.py`: import words from JSON (`[{text|word,start,end,speaker?}]` or `{words}`), SRT, VTT. A `local` provider is just a registered stub raising NotImplemented with a clear message.
- `proxy.py`: build 720p H.264 + AAC proxy with faststart, keyed by source fingerprint; skip if present and valid. `peaks.py`: Int8 min/max peaks file (N samples per second) from ffmpeg PCM pipe.
- Worker entry points (`python -m post_core.ingest.worker proxy|peaks|transcribe …`) that speak the T03 contract (emit progress, artifact with sha256, result).
Acceptance: pytest generating tiny test media with ffmpeg lavfi (skip those tests if ffmpeg missing): probe values, proxy created and idempotent, peaks length/range, importers (JSON/SRT/VTT), Deepgram mapper fixture, worker run through T03 runner yields outcome ok with verified artifact.
Only touch `post_core/ingest/` and `tests/ingest/`. Do not edit pyproject.toml.
