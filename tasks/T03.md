# T03 worker contract + runner
Goal: run any external script as a worker with a uniform, observable contract.
Read first (read-only): `~/cc/post/backend/app/runner.py` (port its good parts: line streaming, process-group kill, finalizers, PYTHONUTF8, ##POST parsing), audit §3 weaknesses.
Build under `packages/post_core/post_core/workers/` and `packages/post_core/tests/workers/` ONLY (do not edit pyproject.toml or other dirs; stdlib only):
- `contract.py`: event kinds `step, say, warn, err, progress{i,n,label}, prompt{text,model}, cost{amount,unit,provider}, artifact{path,role,sha256}, result{ok,detail}`; line format `##POST {json}`; exit codes 0 ok,1 failed,2 usage,3 retry-later(provider limit, optional `retry_at`),4 needs-human.
  `emit(kind, **data)` helper for Python workers; a 10-line bash `post_emit` function as a string constant/file for shell workers.
- `runner.py`: `run(cmd, cwd, env, timeout, on_event, finalizer) -> RunResult(exit_code, outcome, events, artifacts, cost_total, tail)`. New session/process group; kill group on timeout/cancel;
  finalizer always runs and cannot mask the real result; heartbeat (no output for N s → `stalled` event, not a kill). Outcome = ok only if exit 0 AND a `result{ok:true}` event AND every declared artifact exists with matching sha256. Otherwise failed/retry_later/needs_human/interrupted.
- `legacy.py`: adapter for scripts that do not speak the contract: caller supplies expected artifact paths; success = exit 0 + artifacts exist and are non-trivial.
Acceptance: pytest using tiny fake worker scripts written to tmp: success, zero-exit-without-result = failed, missing artifact, sha mismatch, timeout kills children, cancel, finalizer on every path, exit 3 with retry_at, stalled heartbeat, non-UTF8 output.
