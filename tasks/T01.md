# T01 brandkit
Goal: one versioned brand kit per client, compiled into what each tool expects, with lint that can fail.
Read first (read-only): `~/cc/animator/acme/DESIGN.md`, `~/cc/animator/acme/_brand/{brand.css,brand_lint.py,assets/}`,
`~/.claude/skills/hyperframes-creative/references/design-spec.md` (target schema), and in
`~/.claude/skills/animate-captions/` the script build_captions.py (which keys it reads: fonts.body, palette_<dark|light>.brand …).
Plan §8 and audit §7 in `~/cc/vl/brain/projects/` if needed.
Build in `packages/brandkit/` (own pyproject, deps: pyyaml only):
- `schema.py`: load+validate `brand.yaml`: colour roles (hex, max coverage ratio), type roles (family, file, fallback),
  logos (variant → svg path, clear-space, min size, placements per aspect 16:9/9:16), motion (ease, durations, forbidden),
  caption style, sfx palette, names (allow/forbid), characters (id, refs), look (photographic, prose). `kit_hash()` = sha256 over yaml + asset bytes.
- `kits/acme/brand.yaml` + copied SVG assets, faithfully derived from the Acme sources above. Note anything you had to guess in `kits/acme/NOTES.md`.
- `compile.py` → out dir: `brand.css`, `design.md` (hyperframes-creative schema), `captions.json` (keys animate-captions reads),
  `image_prompt_fragment.txt` (photographic look only: MUST contain no hex codes, font names, logo/brand words, or quoted text), `kit.json` (hash, version).
- `lint.py`: source lint for a HyperFrames composition dir (hexes ⊆ palette, font families ⊆ kit, brand.css linked, logo file hash unchanged, forbidden names absent) → JSON report, exit 1 on violations. Prompt lint: `lint_prompt(text)` flags hexes/font names/brand tokens.
- CLI: `python -m brandkit compile <kit> <out>`, `lint <kit> <composition_dir>`, `hash <kit>`.
Acceptance: pytest covers validation errors, deterministic hash, each compiler output, fragment purity, lint pass + each failure class (fixtures in tests). Compiling the Acme kit works.
Out of scope: rendered-frame/vision checks, touching live skills.
