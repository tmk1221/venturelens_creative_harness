# T12 recipes: generation graphs over the existing generators
Goal: real node types and recipe templates, wrapping today's tools as contract-speaking workers. Tests use fakes; nothing paid runs.
Read first: `post_core/graph/`, `post_core/queue/`, `post_core/workers/`, `packages/brandkit` prompt builders (`still_prompt`, `motion_prompt`, `animation_brief`), audit §5 in `~/cc/vl/brain/projects/post-v3-audit-current-app.md` (script interfaces), and read-only: `~/.claude/skills/broll-pipeline/scripts/{gen-stills.sh,gen-videos.sh,gen-endframe.sh,animate.sh}`, `~/.claude/skills/higgsfield/SKILL.md` (CLI contract: `higgsfield generate`, `generate cost`, `model get`).
Carry-over: register the `workflow` kind in `post_core/store` (KIND_MODELS) and make `cli/context.py` use it instead of its private persistence; record fps/duration on produced video assets (ffprobe in the worker) so export no longer assumes conformed clips.
Build `packages/post_core/post_core/recipes/`:
- Node types: `brief.write` (agent, text out), `still.generate` (n variants; params: model, aspect, count; inputs: prompt, optional continuity images `many`; spends; lane remote), `human.pick` (exists), `motion.from_frame` (agent rewrites motion prompt from the picked frame), `endframe.generate` (optional), `video.generate` (inputs: start image, optional end image, motion prompt; duration = ceil(span seconds)+1; spends), `animation.design` / `animation.draft_render` / `human.approve` / `animation.render` (HyperFrames; design is an agent job, lane design; render lane render; brand lint runs as part of design's check and can fail), `overlay.measure` + `overlay.cutout` (optional), `provided.clip` (source asset + in/out), `asset.verify` (resolution/fps/duration/alpha/audio probe).
- Workers live in `recipes/workers/*.py`, speak the T03 contract, call the Higgsfield CLI / hyperframes CLI directly with explicit inputs (do NOT shell to the old bash scripts; do not import from `~/.claude/skills`). Every paid worker emits `prompt`, `cost`, `artifact`. A `POST3_FAKE_PROVIDERS=1` mode produces tiny placeholder media with ffmpeg so the whole graph runs offline.
- Model contracts: `models.py` reads `higgsfield model get <id>` JSON (cached on disk) to build the node's param schema and valid inputs; `estimate_cost` calls `higgsfield generate cost`. In tests both are served from fixtures.
- Prompts come from brandkit builders; the style-block version/hash and kit hash enter the node's input hash. A kit with a pending style block → node state `needs_human` with a clear reason, not a crash.
- Recipe templates (`templates/*.json` + `instantiate(recipe_id, span, kit, look)`): `live_action`, `motion_graphic`, `overlay`, `provided`. Each declares which params are exposed on the simple card view (`exposed: [...]`) and its human gates.
- Cast registry (project level, `store` kind `cast`): character/location entries whose anchor is an approved asset hash; `still.generate` takes anchors as continuity inputs; a beat using "Dave" before Dave has an approved anchor is `blocked` on that beat's pick.
Acceptance: pytest, fake providers: instantiate each recipe for a span; plan shows cost from fixtures; run live_action end to end (stills → blocked on pick → pick → motion → video ≥ span+1 s → verify); changing the style block version marks stills stale but keeps old outputs; cast anchor dependency blocks then unblocks; animation path fails on a brand-lint violation and passes after fix; no worker runs a paid command unless authorised.
Touch `post_core/recipes/`, tests, and the carry-over files only. `brandkit` becomes a path dependency of post_core (optional extra `recipes`).
