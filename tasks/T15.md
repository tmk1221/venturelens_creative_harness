# T15 A-roll regeneration as a take
Goal: select words → "Regenerate line" → a synthetic take attached to that range, reviewable and reversible. Research: `~/cc/vl/brain/projects/post-v3-research-aroll-regeneration.md` §4–5 (API flows, metadata, failure modes).
Build in `post_core/recipes/aroll/` + node types + a recipe `aroll_patch` with three modes: `audio_only` (default; TTS → loudness match to the surrounding passage (ebur128) → room-tone bed from a detected silence in the same source → replaces audio under a picture span), `lipsync` (TTS → lip-sync provider on the source clip range + handles → new video asset), `twin` (TTS → avatar provider → new A-roll asset; also used for hook/CTA variants = N alternative openings stored as cut variants, carrying a `variant_id` for later analytics).
Provider protocols + adapters: `TTSProvider` (ElevenLabs: text→speech with voice id, and speech→speech from a guide recording), `LipsyncProvider` (HeyGen lipsync first; sync.so adapter optional behind the same protocol), `AvatarProvider` (HeyGen video from `audio_asset_id` + avatar id; poll; download promptly). Keys/ids from config/.env (never logged). Per-client pronunciation list comes from the brand kit's `animation.names.pronunciation`. Every call emits prompt/cost/artifact events; results cached by input hash; provider-limit → exit 3.
Model: a synthetic take = Asset(role aroll_synthetic, mode, provider, voice/avatar ids, source range, text, consent_ref) + an edit op `attach_take(range, asset)` / `detach_take`; export places it on V1 (or audio only) with a marker "SYNTHETIC"; deliverables record `contains_synthetic: true` for platform AI-labels. Refuse to run if the project has no `consent` record for that presenter (file path to the signed release + date) — enforced in core.
Tests: fake providers only (generated tone/video); consent gate; loudness within ±1 LU of neighbours; handles respected; variant sets; export markers. Real calls belong to a supervised session like T18.
