# T35 transcription that survives a real 43-minute episode, with speaker names
Why: the Deepgram adapter has never been called for real and would likely fail on the first real file:
- `ingest/transcribe/deepgram.py` reads the whole file into memory and posts it as `audio/wav`.
- CLI and API pass `source.path` (the camera/video file), not the `.m4a` audio proxy
  (`cli/commands/ingest.py:101`, `post_api/routes/ingest.py`).
- The API never loads `.env` (`load_env` is called only in `cli/main.py:234`).
- The request blocks for up to 30 min.
- Speakers stay `SPEAKER_00` and the `local` provider is a stub.
Deepgram costs money, so it must go through the T31 authorisation like any other spend.
Read first: `ingest/transcribe/{base,deepgram,importer}.py`, `cli/config.py` (`load_env`), `cli/commands/ingest.py`,
`post_api/routes/ingest.py`, `post_api/serve.py`, `queue/` (T31 rules), `~/.claude/skills/transcribe/SKILL.md`
(speaker-naming step) and `~/.claude/skills/footage-ingest/scripts/transcribe.py` (reference request), read only.
Build:
1. Transcribe the group's audio proxy (`audio_proxy_path`), sent as `audio/mp4` and streamed from disk with a
   Content-Length (no whole-file read). Error if no audio proxy yet ("run ingest audio first").
2. Transcription is a queued `spends` job (lane `remote`), estimated as minutes × the configured Deepgram rate
   (`usd`), authorised against a budget like any spend (T31); progress events; the transcript is written atomically
   and linked to the sync group. The API calls `load_env()` at startup (never overrides real env vars, never logs
   key values).
3. Speaker naming: `post transcript speakers <id> --map SPEAKER_00="a podcast host" --map SPEAKER_01="Andrew Keen"`;
   API + editor UI: click a speaker label → rename everywhere, with a "play a sample" button that plays that
   speaker's longest utterance from the audio proxy. Names are stored on the transcript, not baked into word text.
4. Keep `local` as a stub but make its error point to `import-transcript` as the free path.
Acceptance: pytest with a fake HTTP server (no network): streaming upload, content type, proxy path used, missing proxy
refused, unauthorised spend refused, estimate correct for a 43-min proxy, `.env` loaded by the API without
overriding env; speaker map persists and survives re-import; Playwright (mocked) rename + sample playback. No real
Deepgram call in this task; Travis runs the real one (H7).
Out of scope: local Whisper provider, caption files.
