# T34 new project from a local recording: one CLI command and a working Ingest page
Why: starting a real project takes six CLI calls (`post init`, `source add`, `ingest audio`, `ingest peaks`,
`import-transcript`, `cut new`) and the web Ingest page is a placeholder (`web/src/App.tsx:13`). Typing a footage
folder as the project root in the UI writes `.post3/` (and later `exports/`) onto the footage drive
(`post_api/routes/projects.py:30-42`). First real use: one ~43-minute remote two-person recording (Show #37,
a podcast host + Andrew Keen), single file, no external audio.
Read first: `cli/commands/{project,ingest,cut}.py`, `post_api/routes/{projects,sources,ingest,cuts}.py`,
`scripts/import_acme_demo.py` (what a real import needed), `ingest/{audio_proxy,peaks}.py`, T22 spec, `web/src/App.tsx`.
Build:
1. Core op + CLI `post project new <name> --root <project_dir> --source <file> [--source …] [--kit <id>]`: init the
   store, add each source (read-only, fingerprinted; one sync group per file), build audio proxy + peaks, set the kit
   (T33). Idempotent: re-running skips finished steps. Refuse a project root that is a source's own folder, sits
   under a source's folder, or is under `/Volumes` (sources may live there; the project may not). JSON out per step.
2. Same op over the API as a job with SSE progress (`step`, `progress`), not a blocking request.
3. Web Ingest page: form (name, project folder, source file paths, brand kit) → live step list with progress and
   failures in plain words → when audio is ready: "Transcribe…" (T35) and "Import transcript…" (file picker path) →
   when a transcript exists: "Open editor", which creates the first cut from the transcript if none exists.
4. Editor performance check on a long show: a synthetic 45-minute, two-speaker transcript (fixture, ~7,000 words)
   opens and scrolls without jank; record load time in the test output.
Acceptance: pytest for the op (temp dirs + `ffmpeg lavfi` media; root-placement refusals; idempotent re-run); API test
of the job + events; Playwright (mocked API) through the Ingest form to "Open editor"; the 45-minute fixture opens in
under 2 s in Playwright. A CLI smoke run on a generated 60 s two-voice file finishes and produces an editable cut.
Out of scope: multicam/external-audio sync (use the `footage-ingest` skill and import its groups; a later task),
downloading media from URLs (H5 is manual), transcription itself (T35).
